# Kepoco Tetris

A Tetris-style game independently developed in Python for the Kepoco platform as part of my first-year Computer Science coursework at the University of Kent.

## Features

- **Block Movement:** Move falling pieces left and right.
- **Block Rotation:** Rotate pieces during gameplay.
- **Collision Detection:** Prevent pieces from moving through occupied cells or outside the playing area.
- **Row Clearing:** Detect and remove completed rows.
- **Score Tracking:** Track the player's score throughout the game.
- **Game Over Detection:** Detect when no further pieces can be placed.
- **Restart Functionality:** Allow players to restart after losing.

## Technologies Used

- Python
- Kepoco platform and library

## Skills Demonstrated

- Python programming
- Game logic and control flow
- Two-dimensional grid manipulation
- Collision detection
- Problem-solving and debugging

## Running the Game

The game was developed for the Kepoco environment and uses the Kepoco Python library for display and button controls. It is not designed to run as a standard desktop Python game without the required environment.
